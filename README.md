# RAVM-DT

Research materials for manuscript CMC 92902. This repository is being prepared; code, figures, results, configurations, and checkpoints have not yet been published here. It is not yet a self-contained reproducibility package.

## Data access

The raw datasets are obtained separately from their providers; they are not included in this repository.

- [Alibaba Cluster Trace 2018](https://github.com/alibaba/clusterdata/blob/master/cluster-trace-v2018/trace_2018.md): follow the provider's access instructions for `machine_usage.tar.gz`. The provider lists SHA-256 `3e6ee87fd204bb85b9e234c5c75a5096580fdabc8f085b224033080090753a7a`.
- [QUANT sensor data](https://zenodo.org/records/10775692): follow the provider's download and attribution instructions for `QUANT_SensorSystems_hourly.csv`. The study file has SHA-256 `a8fa398aacd7bb5c5c320df6675a8dccb146d4e44d0c6f392b4d5acf76fc4d1f`.

Please consult each provider's terms before use. The full set of Alibaba-derived inputs and model checkpoints has not been cleared for public redistribution, and the public reconstruction workflow for those inputs is not yet available here.
