# Synthetic experiment inputs (partial release)

Contains author-generated synthetic inputs, source and initial checkpoints, and configuration for Main, E1, E2 and E5 in both manuscript versions. The subset manifest is newly generated for this publication and is not the historical full 17-group manifest. Alibaba and measured-domain data and weights are not included. The frozen code may reference further files; a complete fresh environment run has not been established. Presence or checksum verification of these files is not a full rerun or proof of end-to-end reproduction. Do not interpret the subset as the full paper.
